Evaluation

Every claim about this pipeline is backed by a measured run. The harness uses Ragas with four metrics — faithfulness, answer relevancy, context precision, context recall — judged by a hosted LLM against a curated test set. Three experiments are shown below; they run in order and tell a story.

About the metrics

  • Faithfulness — fraction of claims in the answer supported by the retrieved context. The hallucination metric.
  • Answer relevancy — how directly the answer addresses the question, scored by semantic similarity to the original question.
  • Context precision — fraction of retrieved context that is actually relevant to the reference answer. Penalizes noisy retrieval.
  • Context recall — fraction of the reference answer's claims that the retrieved context covers. Penalizes missing-info retrieval.

Earlier ablation runs with a weaker local judge gave a noisier and (in one case) misleading verdict — a reminder that, in LLM-as-judge evaluation, judge quality materially shapes the conclusion. The numbers above are the second pass with a stronger judge.

Test set, harness, and saved reports are versioned in the GitHub repository.
